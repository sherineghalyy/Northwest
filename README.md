# NorthWest

Website for NorthWest (Alexandria, Egypt): precision parts and engineering for iron & steel and heavy industry.

Pages: `index.html` (Home), `about.html`, `products.html`, `departments.html`. The Request pop-up is built into every page. Images are in `img/`.

Open `index.html` in a browser, or host the folder with GitHub Pages (Settings → Pages → deploy from `main` branch, `/` root).

Note: the request form has no backend yet; submissions are not sent anywhere.
